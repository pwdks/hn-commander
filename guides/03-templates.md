# 템플릿

## A. 프로젝트 지침 파일 (`CLAUDE.md` 또는 `AGENTS.md`)

```markdown
# <프로젝트 이름>

<한두 줄: 무엇을 하는 프로젝트인지>

## 문서 안내 (필요한 것만 읽을 것)
- 진행 상황: docs/progress.md (세션 시작 시 이것부터)
- 결정 사항: docs/decisions.md (기준 문서보다 우선)
- 기준 문서: docs/spec.md — 1 개요 | 2 구조 | 3 API | 4 DB (필요한 절만)
- 역할 지침: docs/roles/ (요청에 맞는 역할 파일을 따를 것)

## 스택·구조
- <언어/프레임워크/DB>
- <주요 폴더와 역할 한 줄씩>

## 명령어
- 설치: <명령>
- 전체 테스트: <명령>
- 파일 하나 테스트: <명령> <경로>
- 타입 검사/린트: <명령>
- 실행: <명령>

## 절대 규칙
- <지키지 않으면 안 되는 것. 확인 가능한 문장으로>
- 비밀 파일(.env, 키, 인증 파일) 읽기 금지
- 삭제, 강제 푸시, 배포, 외부 전송은 먼저 물어볼 것
- 새 의존성 추가 전에 물어볼 것
- 실행하지 않은 결과를 지어내지 말 것. 못 돌렸으면 "확인 못 함"

## 작업 방식
- 큰 변경(파일 5개 이상, 구조 변경)은 계획 먼저, 승인 후 진행
- 같은 오류 3번 실패하면 멈추고 원인·시도·가설 보고
- 요청 밖 리팩터링 금지

## 토큰 절약
(02-token-efficiency.md의 "지침 파일에 넣을 줄"을 붙인다)
```
